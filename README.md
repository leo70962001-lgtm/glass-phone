# 玻璃主畫面（three.js，手機上跑）

手機全螢幕的主畫面 UI：厚玻璃圖示、ComfyUI 做的絲帶動畫桌布、陀螺儀視差、粉塵消散刪除。

**線上（手機直接開）：https://leo70962001-lgtm.github.io/glass-phone/**　更新：`node tools/publish.js "說明"`（commit、push、GitHub Pages）。

```
node server.js
```
- 電腦：http://localhost:5215（桌機用直式欄預覽，滑鼠移動 = 視差）
- 手機（同一個 Wi-Fi）：**https://<電腦 IP>:5216**（啟動時會印出網址）。憑證是自簽的（`sh tools/cert.sh` 產生，換網路／IP 要重跑），第一次會跳警告，按「進階 → 繼續前往」。陀螺儀一定要 HTTPS；iPhone 第一次觸碰螢幕會詢問「動作與方向」權限。
- 可「加入主畫面」：standalone、直式，狀態列透明（用手機自己的狀態列與瀏海，畫面用 safe-area 避開）。

## 操作
- 傾斜手機 → 眼睛相對螢幕移動（離軸投影），玻璃塊像真的凸出螢幕；光源固定在世界時陰影、焦散也跟著動。沒有陀螺儀時在空白處拖曳。
- 按住圖示 → 玻璃下沉、陰影縮短、微亮。
- **長按（圖示或空白桌布）→ 編輯模式**（圖示抖動、左上角「−」、右上「完成」）。按「−」：先拍下當下畫面，玻璃與名稱由左往右被掃成粉塵（顏色取自圖示本身、往右上飄散淡出，前緣微微發光），消散完其他圖示滑過來補位（Dock 置中重排）。點空白或「完成」離開；左上「還原」把刪掉的圖示反向掃回來。刪除狀態存在 localStorage。全部刪光時畫面中央會出現「重設主畫面」。
- 右上 ⚙ → 面板（手機是底部抽屜）。

## 面板
- 玻璃：厚度、倒角、圓角、頂面弧度、IOR、色散、霧面、顏色濃度、內部反射、乳白霧感、圖案深度／大小／柔化、Dock 托盤厚度
- 立體強化：立體強度（總）、光源方位／仰角／固定在世界、陰影、接觸陰影、焦散、彩虹、星芒、反射、邊緣高光、鏡面高光、環境亮度
- 體感視差：開關、視差角度、觀看距離（越小越立體）、自動擺動、重新校正
- 桌布：絲帶動畫（ComfyUI）／絲帶靜態（Gemini）／程式流光／上傳圖片或影片；動畫開關
- 刪除圖示（粉塵消散）：編輯模式、還原所有圖示、粉塵密度、消散時間、飄散時間、風力、粉塵色調、色調混合
- 效能：玻璃畫質（手機預設「低」：步數少、色散單次）、最高解析度倍率、FPS；連續低於 40 FPS 會自動降倍率

## 做法
- `js/screen.js` 螢幕層：桌布（影片每個新影格才重算）＋名稱／頁面點＋玻璃投下的陰影、倒角焦散、星芒 → 跟畫面同解析度的 sRGB render target（含 mipmap）。
- `js/glass.js` 玻璃：每顆圖示一個包圍盒，對圓角方塊＋倒角＋頂面弧度 SDF 光線追蹤（折射、側壁全反射、底面落到螢幕、glyph 平面、RGB 色散、吸收、霧化）；畫質用 #define 切換。
- `js/layout.js` 版面：以 375×812 參考圖量測為基準，依螢幕寬縮放、依可用高度收列距、避開 safe area。
- `js/dust.js` 粉塵：同一個雜訊門檻函式給玻璃（挖掉）、螢幕層（擦名稱、淡出陰影）、粒子（剝落時間）共用；粒子在頂點著色器裡依門檻決定何時剝落、從刪除當下的畫面快照取色。
- `js/main.js` 離軸相機（螢幕平面永遠填滿畫面）、陀螺儀高通（只對動作反應、放著會回正）、按壓、依需要重畫、自動降解析度。

## 桌布素材
- `assets/silk1.jpg`：Gemini 生成（原檔 `D:\ai\gemini\glass-phone\wallpaper\silk1.png`）
- `assets/silk1-loop.mp4|webm`：本機 ComfyUI MiniMax H3，首幀 = 尾幀無縫循環  
  `py tools/comfy_loop.py <桌布.png> <名稱> tools/comfy/silk-prompt.txt 5 1 448 960` → 用 `tools/loopcheck.py` 看動態與接縫（H3 會在頭尾各停約半秒，已剪成 8–105 格，4 秒循環）
- `assets/wallpapers.json` 決定選單與預設（第一個）

## 開發
`window.__shot('name')` 把目前畫面存到 `tools/shots/`；`window.__advance(ms)` 用固定 60 fps 步長推進動畫（預覽面板在背景時 rAF 會被節流），`__advance.off()` 交還；`tools/compare.py` 舊版（帶機身）與參考圖並排用。
