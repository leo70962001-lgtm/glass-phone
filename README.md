# 玻璃主畫面（three.js，手機上跑）

手機全螢幕的主畫面 UI，有兩種玻璃：**透鏡模式**（預設，薄的液態玻璃：邊緣透鏡、高斯模糊、自動明暗）和 **3D 模式**（光線追蹤的厚玻璃）。玻璃靠近會融在一起；ComfyUI 做的絲帶動畫桌布、陀螺儀視差、粉塵消散刪除。做法參考 [Good Machines Lab 的分析](docs/liquid-glass-analysis.md)。

**線上（手機直接開）：https://leo70962001-lgtm.github.io/glass-phone/**　更新：`node tools/publish.js "說明"`（commit、push、GitHub Pages）。

```
node server.js
```
- 電腦：http://localhost:5215（桌機用直式欄預覽，滑鼠移動 = 視差）
- 手機（同一個 Wi-Fi）：**https://<電腦 IP>:5216**（啟動時會印出網址）。憑證是自簽的（`sh tools/cert.sh` 產生，換網路／IP 要重跑），第一次會跳警告，按「進階 → 繼續前往」。陀螺儀一定要 HTTPS；iPhone 第一次觸碰螢幕會詢問「動作與方向」權限。
- 可「加入主畫面」：standalone、直式，狀態列透明（用手機自己的狀態列與瀏海，畫面用 safe-area 避開）。

## 操作
- **左右滑** → 換頁。第二頁是可拖曳的玻璃卡片和透鏡，以及接真實設定的控制元件：開關（桌布動畫、體感視差）、滑桿（折射，3D 模式是厚度）、分段（液態／清透／3D）。滑塊靜止是白色實心，按住或移動時變成透明玻璃。
- **點 ⋯** → 型變成面板：編輯、玻璃（開設定面板）、控制頁、重設。點空白就縮回去。
- **點＋新增** → 分裂成三顆：桌布（選圖片或影片）、截圖（存 PNG）、錄影（再點上方紅色膠囊停止）。點空白就融回去。
- **拖曳 ⋯ 或＋新增** → 靠近 Dock 或圖示時融在一起、拉出頸部，拉開再分離；放開就停在那裡（位置會記住）。
- **長按圖示約 0.4 秒再拖**（或編輯模式下直接拖）→ 靠近別的圖示先融合，壓到別的格位才換位；可拖進／拖出 Dock（最多四顆）。拖曳時會依速度拉長、停下回彈。排列會記住。
- 按住任何玻璃 → 膨脹、手指位置亮起來（可在面板關掉）。
- **長按（圖示或空白桌布）或面板的「編輯」→ 編輯模式**（抖動、左上角「−」、右上「完成」）。按「−」：玻璃與名稱由左往右被掃成粉塵，消散完其他圖示補位。「還原」把刪掉的圖示反向掃回來。全部刪光時畫面中央會出現「重設主畫面」。
- 傾斜手機（陀螺儀）→ 高光繞著玻璃走、桌布像在玻璃後面一段距離（景深視差）；3D 模式的玻璃會像凸出螢幕。拿著不動幾秒會慢慢回正。沒有陀螺儀時在空白處上下拖曳。iPhone 第一次觸碰會詢問「動作與方向」權限。
- 桌機：可以直接拖放或貼上圖片／影片當桌布，按 R 開始／停止錄影。
- **鯉魚**：只在玻璃裡看得到。2–4 隻一小群，最大的帶頭、其他的排在後面跟著；每到一個圖示就聚在裡面慢慢打轉幾秒，再一起移到上一排，偶爾有一隻脫隊、靠近的小群會合起來。整群從螢幕下緣外面游進 Dock、在圖示裡打轉，再一排一排往上，游出上緣後再從下面游上來；動作全程連續，不會瞬移或憑空出現。魚比圖示大，像從一扇扇玻璃窗底下游過。游法照鯉魚：擺尾的波從頭傳到尾、越往尾巴越大，擺一陣滑一陣，轉彎時整個身體彎成弧形。**點一下圖示**，附近的小群會游過來打轉（以為要餵食）；手指剛碰到玻璃，底下的魚會嚇得急轉。面板「鯉魚」可以關掉、調數量、大小、游速。依據見 [docs/koi-behavior.md](docs/koi-behavior.md)。

## 面板（⋯ → 玻璃）
- 預設：液態玻璃、清透、厚透鏡、霧面、素透鏡、稜鏡（透鏡模式）；3D 厚玻璃、厚透鏡、稜鏡、凹面唇邊、厚果凍、薄玻璃、霧面、水晶塊（3D 模式）。選擇會記住。
- 融合與觸碰：融合距離（兩塊玻璃距離小於這個值就連起來）、果凍感、觸碰反應
- 透鏡模式：透鏡（折射、邊緣寬度、放大、色散、唇邊、大玻璃折射更強、圓角、浮起高度）、表面（模糊、霧面、鮮豔度、亮度、壓暗亮圖、外觀 自動／亮／暗）、色調（透出底色、染色、圖示玻璃色）、光線（邊緣光、光寬、光源角度、陰影）
- 3D 模式：玻璃（厚度、倒角、圓角、頂面弧度、IOR、色散、霧面、圖案…）、立體強化（光源、陰影、焦散、星芒、反射…）
- 體感視差、桌布、刪除圖示（粉塵消散）
- 工具：存成圖片、錄影、複製這組參數的連結（`#p=`）
- 效能：3D 玻璃畫質、最高解析度倍率、FPS 與量到的螢幕更新率。太慢會自動降解析度，順了再升回去；低電量模式的 30 Hz 不算慢。

## 做法
- `js/screen.js` 螢幕層：桌布（影片每個新影格才重算）＋控制元件軌道＋名稱／頁面點＋陰影（3D 模式還有焦散、星芒）→ 跟畫面同解析度的 sRGB render target（含 mipmap）。
- `js/pyramid.js` 高斯金字塔：逐級模糊、減半，存進同一張貼圖的 mip；任何模糊半徑都只要一次 `textureLod`。
- `js/lens.js` 透鏡模式：2D 距離場。邊緣高度用凸面超橢圓，由斜率和 Snell 定律算取樣偏移（一半以上的彎折在最外 3 pt）；霧面、底色、鮮豔度、整圈細亮線；圖案和文字畫在玻璃上，單色的會換深淺。
- `js/tone.js` 自動明暗：把螢幕層縮小、非同步讀回，存線性亮度；小玻璃依底下亮度翻面（有遲滯），文字用比玻璃快的彈簧切換。
- `js/glass.js` 3D 模式：每塊玻璃一個包圍盒，對圓角方塊＋倒角＋頂面弧度 SDF 光線追蹤（折射、側壁全反射、glyph 平面、色散、吸收）；畫質用 #define 切換。
- `js/liquid.js` 融合：找出靠得夠近的玻璃。每塊玻璃把鄰居算進距離場，用平滑聯集融成一個表面，材質依距離混合，再只畫離自己近的那一半，所以交界沒有接縫。靜止時半徑小（輪廓才乾淨），拖曳中才加大；沒有鄰居的玻璃不多花效能。
- `js/layout.js` 版面：以 375×812 參考圖量測為基準，依螢幕寬縮放、依可用高度收列距、避開 safe area；第二頁的控制元件也在這裡。
- `js/fish.js` 鯉魚：每隻是一片會擺尾、會彎曲的四邊形，畫進螢幕大小的透明魚層（含 mipmap）；透鏡模式在圖案上面、表面底下疊上去（一樣被折射、被霧面蓋），3D 模式在玻璃裡的一個水平面上取樣。圖是 Gemini 生的六種錦鯉（`tools/fish_atlas.py` 綠幕去背 → `assets/fish.webp`）。
- `js/dust.js` 粉塵：同一個雜訊門檻函式給玻璃、螢幕層、粒子共用；粒子從刪除當下的畫面快照取色。
- `js/main.js` 離軸相機、陀螺儀（依螢幕方向校正）、阻尼彈簧（固定 120 Hz）、拖曳／換位／Dock、型變面板、分裂、換頁、控制元件、存圖／錄影／連結、依需要重畫、自動解析度。面板蓋到圖示時會多畫一層，面板才模糊得到底下的圖示。

## 開發
`window.__shot('name')` 把目前畫面存到 `tools/shots/`；`window.__advance(ms)` 用固定 60 fps 步長推進動畫（預覽面板在背景時 rAF 會被節流），`__advance.off()` 交還；`tools/compare.py` 舊版（帶機身）與參考圖並排用。
