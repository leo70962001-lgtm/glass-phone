# 鯉魚池分析：動作與群體

2026-11-07，為主畫面的鯉魚做的調查。來源分兩種：網路上的研究與飼主文章，以及一段俯拍鯉魚池影片的逐格量測。結論已做進 `js/fish.js`。

## 1. 文獻與飼主觀察

| 主題 | 內容 | 來源 |
|---|---|---|
| 群游傾向 | 鯉魚被稱為「群游性很強的魚」；個體有大膽／膽小之分，大膽的探索快、搶食快 | Huntingford et al. 2010，J. Fish Biol. 76:1576 |
| 野外小群 | 344 條野生鯉魚的 PIT 標記：覓食時間短、小群頻繁重組；大隻的常先到、吃得多 | Hundt et al. 2022，Ecol. Evol. |
| 間距、極化 | 近親鯉科魚（長春鯿、中華倒刺鲃）4 隻一群：平均間距約 0.7–0.8 個身長，移動時極化 0.89–0.92，速度同步 0.78–0.84，約 57% 的時間在游 | Tang et al. 2017，PeerJ 5:e3397 |
| 帶頭 | 活動量大的常在前面，其他的跟著；大隻的領頭者更容易被跟隨 | Tang 2017；機器魚實驗（Frontiers 2020） |
| 互動規則 | 主要對最近的一隻反應；太近時靠變速拉開（排斥），約 2 個身長以外互相吸引 | Herbert-Read et al. 2011，PNAS |
| 池中日常 | 白天鬆散成群慢慢巡游、覓食；晚上一起休息；觀賞鯉會游向人、在水面等餵食 | pondinformer.com、Kodama Koi Farm |
| 游法 | 鯵型游法：波從頭傳到尾、越往尾巴越大；快是靠擺尾頻率；轉彎靠身體彎曲；擺一陣滑一陣 | 見上一輪（README） |

錦鯉沒有專門的群體數據，以上數字是鯉魚或近親的，當成方向而不是精確值。

## 2. 影片量測

影片：[Top view, Koi pond.](https://www.youtube.com/watch?v=8vbths9cdHQ)（固定機位、斜俯拍，約 25 條錦鯉，24 秒）。

做法：
- 在瀏覽器裡暫停影片，截下 t = 2、2.5、3、3.5、10、10.5、18、18.5 秒。
- 用 `tools/koi_analysis.py` 找魚：和水色差很多的區塊，只看池子中央。再算長軸當身長和方向。
- 每兩張相差 0.5 秒的畫面，先扣掉鏡頭晃動，再用最近鄰配對同一條魚，得到速度和真正的游動方向。

| 指標 | 量到的值 | 說明 |
|---|---|---|
| 偵測到的魚 | 15–23 條 | 白色魚和黏在一起的有漏 |
| 最近鄰間距 | 中位數 0.9–1.4 個身長 | 很密 |
| 分群（2 個身長內算同群） | 一大群 11–15 條＋2–8 條的小群＋幾條落單 | |
| 軸向一致度 | 0.1–0.5 | 方向很亂 |
| 移動方向的極化 | 0.27–0.44 | 不是整齊的魚群，是在原地兜圈的聚集 |
| 和最近鄰居的方向差 | 中位數 33–123° | |
| 速度 | 中位數 0.3–0.5 身長/秒，p75 0.6–0.8，最快約 1.7 | |
| 在游的比例 | 61–86% | |

限制：
- 鏡頭是斜的，有透視，近大遠小。
- 黏在一起的兩條魚會被算成一條長的，少數水草被誤判成魚。
- 只有一段 24 秒的影片，而且魚聚在鏡頭前，可能是在等餵食。

數字只能當量級參考。

## 3. 歸納：兩種狀態

| 狀態 | 何時 | 樣子 |
|---|---|---|
| 聚著打轉 | 在某個地方（等食物、覓食點） | 間距約 1 個身長、方向亂（極化約 0.3）、慢（0.3 身長/秒） |
| 一起移動 | 從一處換到另一處 | 小群排好方向（極化約 0.9）、速度同步、跟著大隻的帶頭 |

另外：
- **重組**：小群經常重組，有的脫隊，有的合群。
- **對人的反應**：觀賞鯉會游向人。

## 4. 做進主畫面的規則

| 規則 | 數值 |
|---|---|
| 小群大小 | 1 隻 15%、2 隻 35%、3 隻 35%、4 隻 15%；最大的帶頭 |
| 跟隨位置 | 帶頭魚後方 1.05 個身長 × 名次、左右錯開 0.45 個身長；到位就和牠同方向 |
| 排斥區 | 0.8 個身長（太近就轉開、減速） |
| 打轉 | 每到一個圖示待 1.5–4.5 秒，0.3 身長/秒，繞著圖示中心轉小圈（半徑約圖示半寬的 0.45），每條魚有自己的方向；一個圖示最多兩條，其他的在同一排隔壁的圖示 |
| 移動 | 0.5 身長/秒，全程連續（2026-11-07 改：原本縫隙裡 ×2.2，看起來像瞬移）；出生時從螢幕下緣外面游進 Dock，不會憑空出現 |
| 重組 | 打轉結束時 12% 機率最後一條脫隊；兩群帶頭魚距離在 3 個身長內、合計 ≤ 4 條就合群；落單的會往 160 pt 內有空位的群游過去 |
| 叫魚 | 點一下圖示：320 pt 內的小群加速（×1.4）游進去，打轉 4–6 秒 |
| 大小、數量 | 預設 12 條、身長 72 pt（比 60 pt 的圖示還長，2026-11-09 使用者要求）：一扇玻璃窗只看得到魚的一段。速度倍率預設 0.75，所以巡游約 27 pt/秒（0.375 身長/秒），大魚擺尾也比較慢 |
| 嚇到 | 手指剛碰到玻璃：55 pt 內的魚急轉逃開 |

模擬 3 分鐘的結果（375×812）：

| 指標 | 模擬 | 參考 |
|---|---|---|
| 移動時的極化 | 0.90 | 文獻 0.89–0.92 |
| 群內最近鄰間距 | 中位數 1.06 個身長（p25 0.63、p75 1.57） | 影片 0.9–1.4 |
| 速度 | 中位數 0.49、p75 0.91 身長/秒 | 影片 0.3–0.5 / 0.6–0.8 |
| 小群大小 | 多半 2–3 條 | 文獻：小群、常重組 |
| 魚在玻璃裡的時間 | 79% | — |
| 打轉時的極化 | 0.83 | 影片 0.27–0.44 |

打轉的方向還是比影片整齊，原因有兩個：
- **群太小**：只有 2–3 條，隨機方向的平均本來就有 0.5–0.6。
- **空間太小**：60 pt 的圖示放 24 pt 的魚，牆把方向擠成一樣。

影片裡是 11–15 條聚在一大片水面上。
